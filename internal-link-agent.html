CHALLENGE / SOLUTION

内部リンク施策、こんなお悩みはありませんか？

Before — 従来の課題
  • 被リンクが少ない記事を手動で洗い出すのが大変
  • どの記事から内部リンクを張るべきか判断が難しい
  • 記事数が多いと確認作業だけで数日かかる
  • 担当者によって基準がバラバラで見落としが発生
  • リンク先の見出し位置まで特定するのが手間
After — このツールの解決策
  • SEOツールのSpreadsheetを渡すだけで自動処理が始まる
  • Claude SonnetがAI採点（100点満点・60点以上を採用）
  • 231記事を約50分で処理（APIモード・5並列）
  • 読者層・地理・自然さ・トピック深度の4項目で均一判定
  • リンク設置する見出しまで自動特定してH〜M列に出力

PROCESS

5ステップの自動化フロー

Cowork（Claude Desktop Pro）にSpreadsheetのURLを渡すだけで、以下の処理が自動実行されます。

1
対象記事の抽出
Spreadsheetから被リンク不足かつH列空白の記事を処理対象として取得。H列にデータがある記事はすでに完了済みとしてスキップします。
Google Sheets API
2
記事インデックスの構築
全記事のHTMLをフェッチしてキャッシュ（article_cacheタブ）。タイトル・見出し・本文・キーワードを抽出してインデックス化。2回目以降はキャッシュから即座に参照。
Python requests + Claude Haiku
3
KWマッチングで候補絞り込み
対象記事のキーワードをトークン分割し、インデックスと照合。KWスコアで上位20件を候補として選出します。AIによるキーワード上位概念拡張も実行。
Python（スコアリング）+ Claude Haiku（KW拡張）
4
AI一括スコアリング
候補上位20件をClaude Sonnetに渡し、4項目・100点満点で採点。読者層・地理的一致・読者にとっての自然さ・トピック深度を総合評価。60点以上を採用。
Claude Sonnet（1記事あたり1回の呼び出し）
5
Spreadsheetへ出力
採用記事のURL（H・J・L列）とリンク設置先の見出し（I・K・M列）をSpreadsheetに書き込み。採用なしの場合は「該当なし」と記入。
Google Sheets API
SCORING

AI採点基準（4項目・100点満点）

Claude Sonnetが以下の4項目で候補記事を採点します。60点以上を内部リンク候補として採用します。

採点項目 内容 配点
読者層の一致 利用者側・提供者側・管理者側を自律推定し、両記事の読者が一致するか評価 25点
地理的一致 地名を含む記事同士は地域マッチを必須判定。地域外リンクを排除 15点
読者にとっての自然さ リンクが読者の記事内での流れを妨げないか。文脈上の自然さを評価 35点
トピックの深さと関連性 表面的なキーワード一致でなく、内容レベルの接点があるか評価 25点
合計（採用閾値：60点以上） 100点
