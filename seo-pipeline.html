CHALLENGE / SOLUTION

SEOブログ運用、こんなお悩みはありませんか？

Before — 従来の課題
  • 記事を書いても、公開後の分析・改善まで手が回らない

  • ファクトチェックや内部リンク設計を手動でやると漏れる
  • Search Consoleのデータを見ても、どの記事をどう直すべきか判断に時間がかかる
  • API従量課金だと、記事を量産するほどコストが膨らむ
After — このツールの解決策
  • リサーチから内部リンク設計まで5工程をAIが自動実行
  • プロンプト設計で品質・トーンを均一化
  • ファクトチェック・内部リンク設計も自動
  • Search Console連携で「どの記事を」「なぜ」直すべきかをAIが自動判断・自動リライト
  • Claude Proサブスクのみで運用、API従量課金なし

PROCESS

5工程の記事生成フロー

Playwrightが起動したブラウザ内で、同一のClaude.aiチャットセッションを使い回しながら5工程を自動実行します。各ステップの出力は次のステップにそのまま引き継がれます。

1
Claude.ai Webへ接続
永続ブラウザプロファイルでログイン状態を保持。初回のみ手動ログインが必要で、以降は自動接続されます。
Playwright
2
リサーチ
対象キーワードの検索意図・競合記事・関連データをAIが調査し、レポートとして出力します。
STEP 1
3
記事生成
リサーチ結果をもとに、構成案から本文（8,000字以上）までを一括で執筆します。
STEP 2
4
ファクトチェック
執筆した記事内の事実情報（数字・固有名詞・統計）を再検証し、誤りがあれば修正します。
STEP 3
5
品質向上
読みやすさ・SEO観点・構成の論理性を多角的にチェックし、本文をブラッシュアップします。
STEP 4
6
内部リンク設計 → MDX変換・自動公開
既存記事のサイトマップをもとに関連記事への内部リンクを自動設計（新規会話でコンテキストをリセットし精度を確保）。完成した記事はMDXに変換され、Cloudflare Pagesへ自動デプロイされます。
STEP 5
AUTOMATION

公開後も止まらない。3つの自動化ワークフロー

GitHub Actionsが毎日決まった時刻に起動し、記事を「書いて終わり」にせず、分析・改善までを自動で回し続けます。

AM 6:00

AM 7:00
auto-rewrite
分析結果をもとにAIが自動リライト

TECH STACK

使用技術・ツール

🤖 Claude.ai Web（Playwright自動操作） 🎭 Playwright 🚀 Astro + MDX 🎨 Tailwind CSS ☁️ Cloudflare Pages ⚙️ GitHub Actions 📊 Google Search Console API

フロントエンドはAstro + MDX + Tailwind CSSで構築し、Cloudflare Pagesでホスティング。記事生成はPlaywrightがClaude.ai Webを直接操作するためAPIキーは不要です。GitHub Actions（セルフホストランナー）が毎日決まった時刻に各処理を自動実行します。
